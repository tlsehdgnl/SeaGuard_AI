# SeaGuard AI · 동해 바다행동 안내

**바다를 확인하고, 오늘을 이어가세요.**

망상·추암·어달 해변의 기상·해양 정보를 확인하고, 활동·동행자·이동 여건에 맞는 행동 안내와 동해 지역의 대체 활동을 살펴보는 모바일 웹서비스입니다.

해커톤 신청서의 **정보 확인 → 행동 이해 → 지역 대안 선택** 흐름을 구현합니다. 회원가입이나 위치 권한 없이 이용할 수 있습니다.

> 첫 방문의 기본값은 **외부 모델 예보**입니다. 데이터 모드에서 고정 예시 데이터로 전환할 수 있습니다. 외부 모델 예보도 현장 관측·공식 통제 정보가 아니며, 위험 등급은 검증된 안전 판정이 아닌 MVP 규칙입니다.

## 구현 기능

| 내 상황 선택 | 산책/물놀이, 어린이 동반, 유모차/무단차 이동, 차량/대중교통, 무료 조건, 남은 시간 |

| 지역 대안 | 출처와 확인일이 있는 6개 시설. 후보·조건 확인 필요·제외 사유를 분리 |
| 가족 공유 | 선택 조건을 담은 링크 및 브라우저에서 생성하는 QR. 받을 때 새로 조회 |

| 접근성 | 큰 글씨, 지원 브라우저의 한국어 음성 읽기·중지, 키보드 포커스, 모바일 배치 |
| 오류 처리 | 예보 실패·오래된 값은 ‘정보 확인 필요’. 공식 링크와 기본 행동·대안은 유지 |
| AI 근거 선택 | LLM이 허용된 안내·장소·근거 ID만 선택. 검증된 자료로 문장 구성, 실패 시 기본 안내 |

### 지역 자료와 추천의 한계

초기 후보는 발한도서관, 북삼도서관, 꿈빛마루도서관, 연필뮤지엄, 천곡황금박쥐동굴, 동해무릉건강숲의 실내 체험입니다.

- `backend/app/data/places.json`에 출처·확인일·알려진 휴관일·비용·접근성 상태를 기록합니다.
- 출처 확인은 현장 실사나 실시간 영업 확인을 뜻하지 않습니다. 임시 휴관·공휴일·예약·정원은 방문 전 확인해야 합니다.
- 접근성 자료가 상충하거나 정보가 없으면 ‘확인 필요’로 표시합니다. 계단 등 알려진 제약은 제외 사유로 표시합니다.
- 대중교통 경로·배차, 실제 소요시간을 계산하지 않습니다. 차량 없음/시간 제한 선택 시 확인 전 후보로 분류합니다.
- 도서관 자료실의 무료 이용 조건은 확보한 자료에 명확하지 않아 `unknown`입니다. 무료 조건 선택 시 무료라고 추정하지 않습니다.
- 확인일로부터 90일이 지나면 최신 정보 재확인 대상으로 전환합니다.
- 추천 의견은 서버·지자체로 전송하지 않습니다. 공유 URL에 의견 기록은 포함하지 않습니다.

## 데이터와 AI

예시 모드는 망상 낮음·추암 주의·어달 위험의 합성 시나리오입니다. 외부 모드는 Open-Meteo 기상·해양 API를 사용하며 필수 값·단위·범위·시각·강수 집계 구간을 검사합니다. 조회 실패 시 예시로 자동 전환하지 않습니다.

파고 1/2m, 풍속 6/10m/s의 주의/위험 기준을 적용합니다. 강수 3/7mm 기준은 **1시간 집계에만** 적용하고 15분 등 다른 구간은 등급에서 제외합니다. 예시 모드는 시연용 강수 기준을 적용합니다. 기온은 참고용입니다. 이 기준은 공식 안전 기준이 아닙니다.

LLM 연결은 선택 사항입니다. 키가 없으면 이를 화면에 표시하고 기본 안내를 제공합니다. AI는 JSON으로 안내 ID·장소 ID·해당 장소의 근거 ID를 고릅니다. 서버는 미등록 장소, 다른 장소의 근거, 중복, 예상 밖 필드, 자유 문장 등을 거부합니다. 고정 행동 안내는 AI의 선택과 무관하게 전부 표시합니다. 자유 생성 설명의 유연성보다 근거 검증을 우선한 구현입니다.

LLM 요청은 인스턴스당 분당 12회·동시 2회로 제한하며, 같은 요청은 5분간 최대 64개 캐시합니다. 이는 서버리스 전체 인스턴스에 걸친 전역 요금 한도가 아닙니다. 실제 운영에는 공급자 예산 제한과 분산 요청 제한이 추가로 필요합니다.

## 로컬 실행

Python 3.12 이상과 Node.js 20.19+ 또는 22.12+를 사용합니다.

백엔드:

```bash
cd backend
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Windows에서는 가상환경 활성화 대신 `.venv\Scripts\python.exe`로 명령을 실행할 수 있습니다.

별도 터미널에서 프론트엔드:

```bash
cd frontend
pnpm install --frozen-lockfile
pnpm dev
```

화면: <http://127.0.0.1:5173> · API 문서: <http://127.0.0.1:8000/docs>

저장소는 `pnpm-lock.yaml`을 사용합니다. npm으로도 설치할 수 있지만 의존성 변경 시 기존 pnpm 잠금 파일과 일치시켜야 합니다.

### 선택적 AI 연결

GPT 연결은 `backend/.env.local`에 아래 값을 넣으세요. 이 파일은 Git에서 제외됩니다. 키는 OpenAI API 프로젝트에서 발급하며, ChatGPT 구독과 API 요금은 별개입니다.

```dotenv
OPENAI_API_KEY=여기에_발급한_API_키
OPENAI_MODEL=gpt-4.1-mini
```

백엔드 폴더에서 의존성을 설치하고 환경파일을 명시해 실행합니다. 기존 `.env.local`이 있으면 덮어쓰지 말고 위 두 항목만 추가하세요.

```sh
cd backend
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn app.main:app --env-file .env.local --host 127.0.0.1 --port 8000
```

Vercel에서는 **백엔드 프로젝트 → Settings → Environment Variables**에 `OPENAI_API_KEY`와 `OPENAI_MODEL`을 추가하고 재배포합니다. `VITE_` 접두어나 프론트엔드 파일에 키를 넣지 마세요. 기존 `LLM_API_KEY`, `LLM_API_URL`, `LLM_MODEL`도 호환되며 `OPENAI_API_KEY` 설정이 우선합니다.

관광 코스에서 출발·종료 시간, 식사 횟수(0–3회), 식사 시간을 지정한 뒤 ‘조건 적용’을 누릅니다. 기존 여행 시간 제한도 함께 적용됩니다. 가게별 운영시간은 **방문할 날짜 기준**으로 지도에서 확인하고 `09:00-14:00,17:00-20:00`처럼 입력하세요. `휴무`/`closed`는 방문 제외, 빈 값은 미확인입니다. 자동 실시간 영업시간 조회는 연결되어 있지 않습니다. 식사는 60분, 기타 방문은 40분이며 식사 시작은 지정 시각부터 60분 이내로 제한합니다. 맞지 않는 장소와 부족한 식사 횟수는 따로 표시합니다.

GPT는 후보 장소와 조건을 바탕으로 방문 우선순위와 대화 답변을 제안하고, 서버가 운영 구간·식사·종료 시각을 다시 검사해 시간표를 만듭니다. 거리·이동시간은 좌표 기반 추정이며 실제 도로 경로/교통 시간표가 아닙니다. ‘이 계획으로 AI와 대화하기’는 앱 내부에서 대화하며 방문 순서를 조정합니다. 시간·횟수 변경은 폼을 통해 적용합니다. 상세 일정 조건과 대화는 해당 화면에서만 유지되며 저장/공유 계획에는 포함되지 않습니다. 키 미설정 시 기본 일정은 동작하고 대화에는 설정 안내가 나옵니다.

요청은 인스턴스당 분당 12회, 동시 2회로 제한하며 최근 대화 최대 16개를 전송합니다. 다중 인스턴스 전체에 걸친 과금 제한은 아니므로 공개 서비스의 비용 한도는 OpenAI 프로젝트에서 별도로 관리하세요.

## API

- `GET /api/health`
- `GET /api/beaches`
- `GET /api/risk/{beach_id}?mode=demo|forecast` — 기존 호환 API, 예보 실패 시 503
- `GET /api/guide/{beach_id}` — 통합 안내. 예보 실패 시에도 HTTP 200과 `state=information_needed`, `weather=null`, 기본 행동·대안을 반환

통합 안내 조건: `mode`, `activity=walk|swim`, `children=true|false`, `mobility=any|stroller|step_free`, `transport=any|car|transit`, `budget=any|free`, `time_budget=any|30|60|90|120|180|240`, `exclude=장소ID,장소ID`.

### 관리자 통계

`/admin`에서 백엔드 `ADMIN_TOKEN` 값으로 접속합니다. 키를 프론트엔드 환경변수나
Git에 저장하지 않습니다. LJH `39be619`의 인증·기간/예보 필터·일별 그래프·
관광지 순위·CSV 내보내기를 통합했습니다.

- 여행 시작, 계획 요약 조회, 지도·공식 안내 링크 클릭을 익명 세션으로 집계합니다.
- SDH 전체 방문지와 관광지 목록을 허용하며 LJH의 기존 `hapyung` ID도 유지합니다.
- SDH가 입력받지 않는 출발 시각은 `-1`(미지정), 여행 예정일은 미기록입니다.
  이동수단 미선택도 `-1`로 저장하며 차량 비중의 분모에서 제외합니다.
- 기존 LJH 완료 동선은 읽기 전용으로 표시합니다. 링크 방문을 실제 방문 완료로 만들지 않습니다.
- 통계 전송 실패가 여행 안내·저장·공유를 차단하지 않습니다.

로컬은 SQLite를 사용합니다. `TRAIL_DB_PATH`를 지정하지 않으면
`~/.seaguard/trails.sqlite3`에 저장됩니다. Vercel에서는 영속 PostgreSQL의
`TRAIL_DATABASE_URL`과 백엔드 `ADMIN_TOKEN` 설정이 필요합니다.
기존 LJH의 `seaguard` 스키마를 재사용한다면 `SEAGUARD_PRIVATE_SCHEMA=1`을 유지하고
**배포 전에** `backend/migrations/002_sdh_context.sql`을 적용해야 합니다.
이는 SDH 미지정 값 때문에 기존 CHECK 제약에서 이벤트가 거부되는 것을 방지합니다.
새 일반 스키마는 앱이 테이블을 생성합니다.

프론트엔드 `VITE_API_BASE_URL`은 통합 백엔드를 가리켜야 하고, 백엔드
`CORS_ORIGINS`에는 실제 프론트엔드 주소를 추가합니다. POST 사전 요청도 지원합니다.
로컬 API 포트를 바꿀 경우 `SEAGUARD_DEV_API_TARGET=http://127.0.0.1:8011 npm run dev`로
프론트엔드 프록시를 설정할 수 있습니다.
