# SeaGuard AI · 동해 바다행동 안내

**바다를 확인하고, 오늘을 이어가세요.**

망상·추암·어달 해변의 기상·해양 정보를 확인하고, 활동·동행자·이동 여건에 맞는 행동 안내와 동해 지역의 대체 활동을 살펴보는 모바일 웹서비스입니다.

해커톤 신청서의 **정보 확인 → 행동 이해 → 지역 대안 선택** 흐름을 구현합니다. 회원가입이나 위치 권한 없이 이용할 수 있습니다.

> 첫 방문의 기본값은 **외부 모델 예보**입니다. 데이터 모드에서 고정 예시 데이터로 전환할 수 있습니다. 외부 모델 예보도 현장 관측·공식 통제 정보가 아니며, 위험 등급은 검증된 안전 판정이 아닌 MVP 규칙입니다.

## 구현 기능

| 기능 | 동작 |
| --- | --- |
| 해변 정보 | 세 해변의 파고·풍속·강수량·기온, 위험 신호 및 근거, 출처·시각 표시 |
| 내 상황 선택 | 산책/물놀이, 어린이 동반, 유모차/무단차 이동, 차량/대중교통, 무료 조건, 남은 시간 |
| 행동 안내 | 조건별 기본 안내를 유지하고 공식 특보·너울·관광 안내 링크 제공 |
| 지역 대안 | 출처와 확인일이 있는 6개 시설. 후보·조건 확인 필요·제외 사유를 분리 |
| 가족 공유 | 선택 조건을 담은 링크 및 브라우저에서 생성하는 QR. 받을 때 새로 조회 |
| 즐겨찾기 | 이 브라우저에 조건 1개 저장·불러오기·삭제. 공유 링크가 우선 |
| 추천 피드백 | 이동/비용/어린이/시간 사유로 이번 목록에서 후보 제외. 로컬 의견 최대 30건, 삭제 가능 |
| 접근성 | 큰 글씨, 지원 브라우저의 한국어 음성 읽기·중지, 키보드 포커스, 모바일 배치 |
| 오류 처리 | 예보 실패·오래된 값은 ‘정보 확인 필요’. 공식 링크와 기본 행동·대안은 유지 |
| AI 근거 선택 | LLM이 허용된 안내·장소·근거 ID만 선택. 검증된 자료로 문장 구성, 실패 시 기본 안내 |

### 지역 자료와 추천의 한계

초기 후보는 발한도서관, 북삼도서관, 꿈빛마루도서관, 연필뮤지엄, 천곡황금박쥐동굴, 동해무릉건강숲의 실내 체험입니다.

- `backend/app/data/places.json`에 출처·확인일·알려진 휴관일·비용·접근성 상태를 기록합니다.
- 출처 확인은 현장 실사나 실시간 영업 확인을 뜻하지 않습니다. 임시 휴관·공휴일·예약·정원은 방문 전 확인해야 합니다.
- 접근성 자료가 상충하거나 정보가 없으면 ‘확인 필요’로 표시합니다. 계단 등 알려진 제약은 제외 사유로 표시합니다.
- 대중교통 경로·배차, 실제 소요시간을 계산하지 않습니다. 차량 없음/시간 제한 선택 시 확인 전 후보로 분류합니다.
- 도서관 자료실의 무료 이용 조건은 확보한 자료에 명확하지 않아 `unknown`입니다. 무료 조건 선택 시 무료라고 추정하지 않습니다.
- 확인일로부터 90일이 지나면 최신 정보 재확인 대상으로 전환합니다.
- 추천 의견은 서버·지자체로 전송하지 않습니다. 공유 URL에 의견 기록은 포함하지 않습니다.

## 데이터와 AI

예시 모드는 망상 낮음·추암 주의·어달 위험의 합성 시나리오입니다. 외부 모드는 Open-Meteo 기상·해양 API를 사용하며 필수 값·단위·범위·시각·강수 집계 구간을 검사합니다. 조회 실패 시 예시로 자동 전환하지 않습니다.

파고 1/2m, 풍속 6/10m/s의 주의/위험 기준을 적용합니다. 강수 3/7mm 기준은 **1시간 집계에만** 적용하고 15분 등 다른 구간은 등급에서 제외합니다. 예시 모드는 시연용 강수 기준을 적용합니다. 기온은 참고용입니다. 이 기준은 공식 안전 기준이 아닙니다.

LLM 연결은 선택 사항입니다. 키가 없으면 이를 화면에 표시하고 기본 안내를 제공합니다. AI는 JSON으로 안내 ID·장소 ID·해당 장소의 근거 ID를 고릅니다. 서버는 미등록 장소, 다른 장소의 근거, 중복, 예상 밖 필드, 자유 문장 등을 거부합니다. 고정 행동 안내는 AI의 선택과 무관하게 전부 표시합니다. 자유 생성 설명의 유연성보다 근거 검증을 우선한 구현입니다.

LLM 요청은 인스턴스당 분당 12회·동시 2회로 제한하며, 같은 요청은 5분간 최대 64개 캐시합니다. 이는 서버리스 전체 인스턴스에 걸친 전역 요금 한도가 아닙니다. 실제 운영에는 공급자 예산 제한과 분산 요청 제한이 추가로 필요합니다.

## 로컬 실행

Python 3.12 이상과 Node.js 20.19+ 또는 22.12+를 사용합니다.

백엔드:

```bash
cd backend
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Windows에서는 가상환경 활성화 대신 `.venv\Scripts\python.exe`로 명령을 실행할 수 있습니다.

별도 터미널에서 프론트엔드:

```bash
cd frontend
pnpm install --frozen-lockfile
pnpm dev
```

화면: <http://127.0.0.1:5173> · API 문서: <http://127.0.0.1:8000/docs>

저장소는 `pnpm-lock.yaml`을 사용합니다. npm으로도 설치할 수 있지만 의존성 변경 시 기존 pnpm 잠금 파일과 일치시켜야 합니다.

### 선택적 AI 연결

`backend/.env.example`을 참고해 `LLM_API_KEY`, `LLM_API_URL`, `LLM_MODEL`을 서버 환경에 설정합니다. `.env`는 자동으로 로드하지 않습니다. URL은 HTTPS chat-completions 호환 엔드포인트이며 JSON 응답 모드를 지원해야 합니다. 지원하지 않거나 출력 검증이 실패하면 기본 안내로 돌아갑니다. 키는 프론트엔드에 넣지 않습니다.

## API

- `GET /api/health`
- `GET /api/beaches`
- `GET /api/risk/{beach_id}?mode=demo|forecast` — 기존 호환 API, 예보 실패 시 503
- `GET /api/guide/{beach_id}` — 통합 안내. 예보 실패 시에도 HTTP 200과 `state=information_needed`, `weather=null`, 기본 행동·대안을 반환

통합 안내 조건: `mode`, `activity=walk|swim`, `children=true|false`, `mobility=any|stroller|step_free`, `transport=any|car|transit`, `budget=any|free`, `time_budget=any|30|60|90|120|180|240`, `exclude=장소ID,장소ID`.
