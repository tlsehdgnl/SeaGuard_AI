# SeaGuard AI

### 바다에 가기 전, 한 번 더 확인하세요.

**SeaGuard AI는 동해시 해변의 기상·해양 정보를 모아 위험 신호와 그 이유를 쉽게 살펴볼 수 있도록 만든 웹 서비스입니다.**

망상·추암·어달 해변을 선택하면 파고, 풍속, 강수량과 기온을 확인할 수 있습니다. 데이터를 규칙에 따라 분석해 위험 신호를 표시하고, 어떤 항목이 결과에 영향을 주었는지 설명합니다.

이 프로젝트는 화면부터 API, 외부 데이터 연결, 배포까지 구현한 **MVP**입니다. 위험도는 규칙으로 계산하며, LLM은 선택적으로 보충 설명을 제공하는 역할을 합니다.

**[서비스 이용하기](https://seaguard-web.vercel.app)** · [API 문서](https://seaguard-api.vercel.app/docs) · [GitHub 저장소](https://github.com/tlsehdgnl/SeaGaurd_AI)

> 기본 화면은 기능 시연을 위한 **예시 데이터**입니다. 실제 관측값이나 현재 해변 상태를 나타내지 않습니다. 외부 모델 예보는 화면에서 별도로 선택할 수 있습니다.

## 프로젝트 소개

해변 방문 전에는 파도와 바람 등 여러 정보를 함께 확인해야 합니다. SeaGuard AI는 이 정보를 한 화면에 모으고, 수치와 분석 근거를 함께 보여주는 것을 목표로 합니다.

단순히 등급만 보여주는 대신 **무엇을 근거로 판단했는지**, **어디에서 가져온 데이터인지**, **언제의 데이터인지**를 확인할 수 있도록 구성했습니다. 예시 데이터와 외부 예보도 명확히 구분합니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 해변 선택 | 동해시 망상·추암·어달 해변별 정보 조회 |
| 기상·해양 지표 | 파고, 풍속, 강수량, 기온 표시 |
| 위험 신호 분석 | 파고·풍속·강수량에 따라 낮음·주의·위험 등급 산정 |
| 분석 근거 | 등급에 영향을 준 항목과 수치 표시 |
| 설명 제공 | 기본 규칙 설명 및 선택적 LLM 보충 설명 |
| 데이터 투명성 | 출처, 데이터 시각, 조회 시각, 예시 여부 표시 |
| 오류 대응 | 로딩, 요청 시간 초과, API 오류 안내 및 재시도 |
| 반응형 화면 | PC와 모바일 화면에 맞춘 배치 |

## 이용 방법

1. [SeaGuard AI](https://seaguard-web.vercel.app)에 접속합니다.
2. 망상·추암·어달 중 확인할 해변을 선택합니다.
3. 파고·풍속·강수량·기온과 위험 신호의 근거를 확인합니다.
4. 데이터 모드에서 **외부 모델 예보**를 선택하면 외부 API의 예보를 조회합니다.
5. 결과 아래에서 데이터 출처와 기상·해양 데이터 시각을 확인합니다.

외부 조회가 실패하면 오류를 표시합니다. 예시 데이터로 전환하려면 사용자가 직접 예시 모드를 선택해야 합니다.

## 데이터와 분석 방식

### 두 가지 데이터 모드

| 모드 | 데이터 | 용도 |
| --- | --- | --- |
| 예시 데이터 — 기본 | 해변별 고정 합성 시나리오 | 화면과 분석 기능 시연 |
| 외부 모델 예보 | Open-Meteo 기상·해양 API | 해변 인근 격자의 기상·해양 예보 조회 |

예시 모드는 망상 **낮음**, 추암 **주의**, 어달 **위험** 시나리오로 구성되어 있습니다. 이는 실제 해변별 위험 수준을 비교한 결과가 아닙니다.

외부 모델 예보도 해변 현장에서 측정한 관측값은 아닙니다. 출처와 데이터 시각을 화면에 표시하며, 필수 값·단위·수치 범위·데이터 시각을 검사합니다. 한국 기상청·해양 공공데이터 관측 API는 아직 연결하지 않았습니다.

### 규칙 기반 위험도

| 분석 항목 | 주의 | 위험 |
| --- | --- | --- |
| 파고 | 1m 이상 | 2m 이상 |
| 풍속 | 6m/s 이상 | 10m/s 이상 |
| 강수량 | 3mm 이상 | 7mm 이상 |

항목별 등급 중 가장 높은 것을 최종 등급으로 사용합니다. 기온은 참고 정보로만 표시하며 위험도 계산에는 사용하지 않습니다. 강수량은 제공 구간의 값이며 외부 예보 모드에서 집계 구간을 함께 표시합니다.

**위 임계값은 MVP 시연용이며 공식 안전 기준이나 검증된 위험 예측 모델이 아닙니다.** 낮음 등급도 입수 안전을 보장하지 않습니다. 이안류·낙뢰·조석·수심·현장 통제 정보는 분석 대상에 포함되어 있지 않습니다.

### AI 설명

위험 등급과 기본 행동 안내는 규칙으로 결정합니다. LLM을 연결하면 입력된 데이터에 대한 보충 설명을 추가할 수 있습니다.

- LLM 키가 없어도 규칙 기반 설명으로 동작합니다.
- LLM 연결이 실패하거나 응답이 올바르지 않으면 규칙 설명을 제공합니다.
- LLM 보충 설명은 규칙 기반 등급과 행동 안내를 대체하지 않습니다.
- API 키는 백엔드에서 관리합니다.

## 로컬 실행

Python 3.12와 Node.js 20.19+ 또는 22.12+ 환경을 권장합니다. 프로젝트 루트에서 터미널 두 개를 사용합니다.

### 백엔드

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
