# 해커톤 자료 반영 및 구현 기록

작성일: 2026-11-20 (Asia/Seoul). 로컬 구현 완료, 공개 서비스 재배포 전.

## 두 자료에서 가져온 방향

사용자가 제공한 정책 발표자료와 팀 참가신청서를 모두 검토했다. 자료 안의 제출·참가 안내는 대회 맥락으로 참고했으며 자동 제출이나 연락, 배포를 수행하지 않았다. 참가자의 연락처·생년월일 등은 코드와 이 문서에 옮기지 않았다.

| 자료 | 내용 | 구현에 반영한 방식 |
| --- | --- | --- |
| 정책 발표자료 PDF 3~5쪽 | 시민이 체감하는 문제, 맞춤형 정보, 포용적 서비스 | 활동·동행자 입력, 쉬운 행동 안내, 큰 글씨·음성 읽기 |
| 정책 발표자료 PDF 7~8쪽 | 정보 탐색 불편 감소, 시민·지역사회 참여 | 공식 확인 경로 한 화면 제공, 추천 의견에 따른 후보 변경 |
| 신청서 PDF 2~3쪽 | 정보 확인에서 행동 선택까지의 간극 | 해변 선택 → 행동 안내 → 지역 대안 흐름 |
| 신청서 PDF 3~4쪽 | 3개 해변·6곳 내외 후보, 근거 기반 AI | 기존 3개 해변 유지, 출처 있는 시설 6곳 등록, ID 기반 AI 선택 검증 |
| 신청서 PDF 4~5쪽 | 누락·오래된 데이터·AI 오류 처리 | 예보 불가 시 등급 제거, 공식 링크·기본 행동 유지, AI 실패 시 기본 추천 |
| 신청서 PDF 5쪽 | 공유 링크·QR, 호출 제한·캐시 | 로컬 QR 생성, 조건 공유, 5분 캐시와 인스턴스 요청 제한 |
| 신청서 PDF 6쪽 | 20개 시나리오, 5명 평가·30초 내 행동 찾기 | 20개 조합 자동 검증 구현. 실제 이용자 평가는 별도 진행 필요 |

신청서에서 계획한 자유 생성 설명은 **AI가 안내·후보·근거 ID를 선택하고 서버가 확인된 문장으로 구성하는 방식**으로 구체화했다. 임의 안전 보장이나 없는 장소를 화면에 노출하지 않기 위한 설계이며, AI 사용은 화면에 명확히 구분한다.

## 추가 기능과 시민의 변화

- 유모차·계단 없는 이동, 차량 없음, 무료 조건, 남은 시간을 입력한다. 확인되지 않은 조건을 충족했다고 추정하지 않아 헛걸음을 줄이는 것을 목표로 한다.
- 가족 공유는 조건만 전달하며 받을 때 새로 조회한다. 예시/외부 모드를 그대로 전달하되 예시 표시를 유지한다.
- 자주 쓰는 조건 1개를 이 브라우저에 저장한다. 저장·복원·삭제와 저장 실패 메시지를 제공한다.
- 이동·비용·아이·시간 문제를 선택하면 해당 장소를 이번 추천에서 제외한다. 의견은 로컬 최대 30건만 저장하고 삭제할 수 있다. 지역사회 통계가 수집된 것처럼 표현하지 않는다.
- 큰 글씨와 브라우저 음성 읽기를 제공한다. 기기별 음성 지원·실제 청취 품질은 추가 확인이 필요하다.

연필뮤지엄의 접근성은 관광공사 자료 사이에 차이가 있어 `step_free=null`로 보관한다. 어린이 요금도 자료가 달라 운영기관의 안내를 우선하고 방문 전 재확인 문구를 붙였다. 동굴 접근 제한은 2019년 관광공사 자료라는 한계를 함께 표시한다. 도서관의 무료 이용 여부는 확인한 자료만으로 단정하지 않고 `unknown`을 사용한다.

일반 후보도 영업 중이라는 뜻은 아니다. 알려진 정기 휴관일은 제외하지만 공휴일·임시 휴관·예약을 자동 확인하지 않는다. 차 없는 이동과 시간 제한은 실제 경로 계산이 없어 추가 확인 목록으로 보낸다. 자료 확인 후 90일이 지나면 후보를 최신 정보 확인 대상으로 전환한다.

## 시연 순서

1. 예시 모드에서 망상·추암·어달을 전환해 합성 데이터와 위험 근거 구분을 보여준다.
2. 물놀이·어린이 동반을 선택해 고정 행동 안내가 달라지는 것을 보여준다.
3. 유모차·차량 없음·1시간을 선택한다. 확인된 적합 후보가 없을 때 억지로 추천하지 않는 빈 상태와 문의할 조건을 보여준다.
4. 후보의 출처와 확인일, 지도 검색·전화 문의 경로를 보여준다.
5. 가족 공유 링크·QR을 열고 다른 브라우저에서도 동일 조건이 복원되는 것을 보여준다.
6. 자주 쓰는 조건 저장 후 새로고침하고, 추천 의견으로 후보를 제외했다가 초기화한다.
7. 외부 예보 모드에서 데이터 출처·시각·15분 강수 집계 표시를 확인한다. 연결 실패 시 ‘정보 확인 필요’가 표시된다.
8. AI 키가 없다면 ‘AI 연결 전’이라고 설명한다. 실제 LLM 연동 시연으로 표현하지 않는다. 오류·악성 출력은 자동 테스트 결과로 제시한다.

## 실제 운영·대회 제출 전에 필요한 일

- LLM 공급자 설정 후 실제 JSON 응답, 지연, 비용을 확인한다. 현재 검증은 모의 성공·실패·잘못된 출력과 키 없는 상태이다.
- 현장 멘토링에서 공식 통제 확인 경로, 안전 안내 문구와 관광 후보의 적합성을 검토한다.
- 접근성·무료 조건·예약을 기관에 재확인하면 JSON의 미확인 값을 근거와 함께 갱신한다.
- 이용자 5명 이상에게 행동 찾기 과제를 주어 30초 이내 성공률 80% 목표를 실제로 평가한다. 자동 테스트 결과로 이 목표 달성을 주장하지 않는다.
- 공개 배포 후 공유 QR, 환경변수, 모바일, 정상·주의·누락·AI 실패를 재검증한다.
- 신청서의 배포 후 30일 접속 유지 목표는 운영 계획으로 별도 관리한다. 이번 작업에서 유지 보장이나 예약 작업은 만들지 않았다.
- 시민 신고·기관 관리자·푸시 알림·통계 수집은 협업 기관과 운영 체계가 필요한 후속 범위로 남긴다.
